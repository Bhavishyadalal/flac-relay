Add a music source

Connect another compatible music addon to FLAC Relay.

  1. Copy the manifest linkIn the other addon's setup page, copy its install or manifest URL. A typical link ends in /manifest.json.
  2. Paste and testFLAC Relay checks that the addon can search for tracks and return a playable link.
  3. Try it in the playerAfter a successful test, the source appears under Sources and is enabled for searches.
